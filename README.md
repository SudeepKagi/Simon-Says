## Overview
Simon Says is a colorful memory game built using HTML, CSS, and JavaScript, featuring smooth animations and modern UI.

## Tech Stack
* Frontend: HTML, CSS, JavaScript

## Features
* Smooth animations
* Modern UI

## Prerequisites
* A web browser to run the game

## Installation
To run the game, clone the repository and open `index.html` in a web browser.

## Environment Variables
No environment variables are required to run this application.

## Usage
1. Clone the repository: `git clone https://github.com/username/Simon-Says.git`
2. Navigate to the repository: `cd Simon-Says`
3. Open `index.html` in a web browser to play the game

## API Endpoints
This is not a backend project, so there are no API endpoints.

## Deployment
To deploy the game, simply host the `index.html`, `app.js`, and `style.css` files on a web server.
