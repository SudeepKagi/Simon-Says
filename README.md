## Overview
Simon Says is a colorful memory game built using HTML, CSS, and JavaScript, featuring smooth animations and modern UI.

## Tech Stack
* HTML
* CSS
* JavaScript

## Features
* Smooth animations
* Modern UI

## Prerequisites
* Web browser

## Installation
To run the game, open `index.html` in a web browser.

## Environment Variables
No environment variables are required.

## Usage
Open `index.html` in a web browser and follow the in-game instructions.

## API Endpoints
This is a frontend project and does not have API endpoints.

## Deployment
To deploy, simply copy the `index.html`, `style.css`, and `app.js` files to a web server.
