# Simon Says 🎮

A simple, colorful **Simon Says memory game** built with **HTML, CSS and JavaScript**.

The game shows a sequence of tiles lighting up. Your job is to **repeat the exact sequence**.  
Each time you succeed, the level increases and the sequence gets longer!

---

## 🖼 Preview

Four bright tiles on a dark background:

- Pink
- Blue
- Yellow
- Green

Centered title **“Simon Says”** with a glowing subtitle like **“Press any key to start!”**.

---

## ✨ Features

- Classic **Simon Says** gameplay
- Clean neon UI with soft shadows
- Level counter that increases as you play
- Tile **flash effect** when active
- **Background flash** when you make a mistake (game over)
- Responsive layout that works nicely on desktop

---

## 🧰 Tech Stack

- **HTML5** – structure
- **CSS3** – layout, colors, glow, animations
- **JavaScript (Vanilla JS)** – game logic (sequence, input, level, game over)
