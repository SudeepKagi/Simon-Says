## ✨ Features

* **✨ Interactive Gameplay:** The game initiates by detecting any keypress (`document.addEventListener("keypress",...)`) and handles player input through click events on colored buttons (`allBtn.addEventListener("click",btnPress)`). This provides a direct and intuitive interface for starting and playing the game within the web browser.

* **📈 Progressive Difficulty:** The game advances through levels (`level++`) and increases complexity by adding a new random color to the `gameSeq` array after each successful sequence completion (`levelUp()` function). This mechanism continuously challenges the player's short-term memory with progressively longer patterns.

* **🎲 Random Sequence Generation:** Each level presents a unique and unpredictable sequence of colors generated by selecting a random index (`Math.random()`) from a predefined array of button colors and pushing it to the `gameSeq` array. This ensures replayability and a fresh challenge with every game attempt.

* **✅ Input Validation:** The `checker(idx)` function meticulously tracks the user's input sequence (`userSeq`) and validates each press against the game's internally generated sequence (`gameSeq`) in real-time. This provides immediate feedback on the correctness of the player's button presses.

* **🌈 Visual Feedback:** The `btnFlash()` function provides clear visual cues by briefly highlighting buttons when they are part of the game's sequence or user input, achieved by toggling a `flash` CSS class. A distinct `bg-flash` CSS class is applied to the document body to signal a game-over event, enhancing the interactive experience.

* **🏆 Game Over & Scoring:** Upon an incorrect guess, the game clearly announces "Game over!" and proudly displays the `level` achieved as the final score directly on the screen via an `h4` element. This immediate feedback informs the player of their performance and the game's conclusion.

* **↩️ Restart Functionality:** The `reset()` function allows for continuous play by clearing all game state variables (`started`, `gameSeq`, `userSeq`, `level`) after a game over. Players can seamlessly restart the game at any point by simply pressing a key, ensuring an uninterrupted gaming experience.

## 🏛️ System Architecture

This project is implemented as a client-side web application, running entirely within the user's web browser. The core game logic in `app.js` directly manipulates the DOM elements defined in `index.html` and styled by `style.css`, responding to user input and managing the game state. The entire application executes synchronously in the browser environment without any server-side components or external APIs.
